# Kosha Documentation Index

## Reading Order for New Sessions
Per project standing rules, read these documents before making changes:
1. [`PROJECT_SPEC.md`](PROJECT_SPEC.md) — Standing rules (strict verification, no invented facts/PYQs, licensed visuals, state preservation).
2. [`V3_TEXTBOOK_SPEC.md`](V3_TEXTBOOK_SPEC.md) — Vision and component anatomy for the Visual Textbook (Learn → Practice → Mistakes).
3. [`V3_1_PYQ_ENGINE.md`](V3_1_PYQ_ENGINE.md) — PYQ metadata, evidence standards (Gold / Silver / Bronze), and verification rules.
4. [`PROGRESS.md`](PROGRESS.md) — Current sprint status, active tasks, blockers, and next milestones.
